Asignatura: Construye Aplicaciones Web - Conceptos clave

Frontend
Es la interfaz visual y la parte del cliente de una aplicación web con la que los usuarios interactúan directamente a través del navegador.
Backend
Es la lógica del servidor encargada de procesar las peticiones, gestionar la seguridad y comunicarse con las bases de datos.
Servidor Web
Es el software o equipo encargado de despachar documentos, recursos multimedia y respuestas a las solicitudes realizadas por clientes mediante el protocolo HTTP.
HTTP / HTTPS
Protocolo de transferencia de hipertexto que rige la comunicación en la Web. La versión HTTPS añade cifrado de seguridad mediante certificados SSL/TLS.
Base de Datos
Sistema estructurado para almacenar, consultar y gestionar grandes volúmenes de información requerida por las aplicaciones web.
API (Interfaz de Programación de Aplicaciones)
Conjunto de reglas y especificaciones que permiten que diferentes sistemas de software se comuniquen e intercambien datos entre sí.
